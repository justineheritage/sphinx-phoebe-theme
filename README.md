# Sphinx Phoebe Theme

Modern, responsive Sphinx theme with AI chat integration and feedback widgets.

## Features

- Modern 3-column responsive layout (sidebar | content | TOC/chat)
- Dark mode with system preference detection
- AI chat integration (RunLLM streaming API)
- Per-page feedback widget (Formspree integration)
- Keyboard shortcuts (/, [, ?, arrows for navigation)
- Mobile-friendly responsive design
